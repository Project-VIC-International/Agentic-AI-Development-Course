# Start Here

This repository contains the course materials.

For the hands-on lab, create your own **private** project from the Project VIC Agentic AI Development Project Template:

<https://github.com/Project-VIC-International/Agentic-AI-Development-Project-Template>

The template works with any AI coding agent (Cursor, Claude Code, Codex, GitHub Copilot, Gemini CLI, and others). The instructor uses Cursor. See `docs/agent-setup.md` in the template for your agent.

During the lab, your private project repository is where you will:

1. Complete the problem intake form.
2. Paste `prompts/START-AGENT-HERE.md` into your agent and ask it to explain the project policies in `policies/`.
3. Tell the agent which country and agency your tool is for, so it plans for the right security rules.
4. Create a milestone plan.
5. Generate specs, plans, and tasks.
6. Build and test with synthetic data.

Do not paste real case data into your AI agent, GitHub, issues, logs, screenshots, test files, or sample data. For this course, all development must use synthetic data.
